`package` takes no children.

## For library authors

Consumers find your package directory through `path`. Without it, a bare import resolves to your repository root:

```txt geometry/
geometry/
  meade.kdl          # package "geometry" version="1.2.3" path="src/geometry"
  src/
    geometry/
      geometry.odin
```

You don't need a compiled-library target for an ordinary source library.
