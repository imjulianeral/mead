`mead.lock` lives beside `meade.kdl`. **Commit it.** `mead install` and `mead update` write it, and other commands only read it. mead rewrites the file only when its content changes, as 2-space-indented JSON with a trailing newline.

```json mead.lock lineNumbers
{
  "version": 1,
  "manifest_hash": "sha256:1f2aeeff7fcff232285a08c3412f5a1da46f6ff90f9cd919e981278306508764",
  "dependencies": [
    {
      "name": "example_pkg",
      "source": {
        "git": "https://github.com/example-author/geometry.git",
        "selector": { "kind": "release", "value": "v1.2.3" },
        "ref": "refs/tags/v1.2.3",
        "object_format": "sha1",
        "commit": "6e93eafa715d63bd5812728df4b8c8ff2b70f3ce",
        "release_id": 184467201
      },
      "requested_path": "src/geometry",
      "package_path": "src/geometry",
      "author_manifest": true,
      "dependencies": []
    }
  ],
  "tools": [
    {
      "name": "assetgen",
      "source": {
        "git": "https://github.com/example-author/assetgen.git",
        "selector": { "kind": "tag", "value": "v0.4.0" },
        "ref": "refs/tags/v0.4.0",
        "object_format": "sha1",
        "commit": "7e1e798f44a1c3b0d0f9a2e6f1d4c7b8a9e0f1d2",
        "release_id": 0
      },
      "distribution": "build",
      "target": {
        "name": "assetgen",
        "kind": "executable",
        "path": "cmd/assetgen",
        "flags": ["-o:speed"]
      }
    }
  ]
}
```

## `manifest_hash`

The hash covers one line per declaration, with fields separated by NUL bytes, in manifest order:

```txt
dependency␀<name>␀<git>␀<selector kind>␀<selector value>␀<path>
tool␀<name>␀<git>␀<selector kind>␀<selector value>␀<distribution>␀<target>
target␀<name>␀<kind>␀<path>[␀<flag>…]
```

`schema`, `package`, comments, whitespace, and property order don't affect it. Reformatting the manifest never invalidates the lock.

## Load-time checks

When mead loads `mead.lock`, it checks the following and stops on any failure:

```txt
mead: error: /…/mead.lock is not a valid mead lockfile: …
mead: error: /…/mead.lock: "geometry" has an invalid commit ID "6e93ea"
mead: error: /…/mead.lock: "geometry" has an invalid ref "tags/v1"
mead: error: /…/mead.lock: "geometry" has an invalid origin: …
```
