<Synopsis cmd="mead versions <git-url>" />

`versions` queries an origin **without fetching any source** and prints every selectable revision, grouped by the selector that would pick it. It doesn't need a project.

## Arguments

<TypeTable
  type={{
    "git-url": {
      type: "string",
      required: true,
      description: "An `https://`, `ssh://`, `user@host:path`, or `file://` origin. It must pass the same [origin validation](/manifest/validation#git-origins) as a manifest, so embedded credentials are rejected.",
    },
  }}
/>

```txt
  nightly                  ffe01d22b9a0  refs/tags/nightly

```

### Sections

<Accordion>
  <AccordionItem title="GitHub releases (GitHub origins only)">
    mead pages through `GET /repos/{owner}/{repo}/releases?per_page=100`. Each release shows its tag, status (`stable`, `prerelease`, or `draft`), the release ID, and the tag's commit (or `(tag not found)` when the tag doesn't exist in Git). If the release has a display name that differs from its tag, mead shows that name too. Assets are listed with ID, size, and digest, but none of them carries target metadata yet.

    If the API fails, the section says `unavailable: <reason>` and the rest of the listing still prints.
  </AccordionItem>
  <AccordionItem title="Version tags">
    These are tags that parse as SemVer `MAJOR.MINOR.PATCH`, with an optional leading `v`, an optional `-prerelease`, and optional `+build` metadata (which mead ignores). They're sorted **newest first** by SemVer precedence. Numbers with leading zeros don't count as versions. Annotated tags show the commit they point to.
  </AccordionItem>
  <AccordionItem title="Other tags">
    All remaining tags, sorted alphabetically.
  </AccordionItem>
  <AccordionItem title="Branches">
    All branches, sorted alphabetically. The branch the remote `HEAD` points to is marked `(default)`.
  </AccordionItem>
</Accordion>

Commits are abbreviated to 12 characters in the listing. Use [`mead add`](/cli/add) with the full value.

## Errors

| Message | Cause |
| --- | --- |
| `usage: mead versions <git-url>` | Missing URL, extra arguments, or an option. |
| `git origin "…": …` | The URL failed validation. |
| `cannot list refs of <url>: …` | `git ls-remote` failed. Git's stderr follows. |
| `the GitHub API rate limit is exhausted (resets at unix time …); set GITHUB_TOKEN for a higher limit` | Shown inside the releases section. |
| `GitHub repository o/r was not found (private repositories need GITHUB_TOKEN)` | Shown inside the releases section. |
